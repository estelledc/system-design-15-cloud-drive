# Security policy

This repository is a bounded learning lab, not a hosted storage product.

Do not submit real bearer tokens, personal files, internal data, malware samples, or production connection strings. Use only
synthetic fixtures and disposable infrastructure. Report suspected secret exposure or unsafe path/authorization behavior through
a private GitHub security advisory rather than a public issue.

The initial contract excludes production identity, encryption/key management, malware/content scanning, legal retention and
erasure, public sharing, tenant isolation, quotas, abuse prevention, replicated durability, backup/restore, and disaster recovery.
